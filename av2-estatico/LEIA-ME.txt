ABERTURA E PUBLICAÇÃO
Esta pasta é independente do framework da prévia Lovable.
Contém HTML5, CSS e JavaScript puros; não precisa instalar, compilar, usar
servidor ou backend. Abra index.html, produtos.html, kits.html, sobre.html
ou contato.html diretamente no navegador. Para o GitHub Pages, copie o
CONTEÚDO desta pasta para a raiz do repositório, deixando index.html na raiz,
ao lado de css/, js/, img/, audio/ e creditos/. Publique a pasta raiz da
branch escolhida. Não copie o projeto Lovable, src/, node_modules/ ou public/.
Os caminhos locais são relativos e foram testados sob /av2-estatico/ em HTTP,
simulando um site de projeto servido dentro de uma subpasta de repositório.
Publicação real no GitHub Pages: PENDENTE; o teste local não substitui essa confirmação.
Fontes Google Fonts e ícones Font Awesome são as únicas dependências externas
permitidas. Precisam de internet; fontes de sistema substituem as fontes remotas.
O carrinho é local e pode variar entre URLs file:// conforme o navegador.
Em HTTP na mesma origem foi confirmado entre páginas e após recarregar.
Compra e contato são demonstrativos: sem cobrança, envio ou coleta de dados pessoais.
